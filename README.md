# Portfolio Template (Sanitized)

This folder is a template-ready copy of the portfolio project with personal details removed.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Files To Customize

- `components/JSONFiles/About.json`
- `components/JSONFiles/ContactInfo.json`
- `components/JSONFiles/Experience.json`
- `components/JSONFiles/Projects.json`
- `components/JSONFiles/Education.json`
- `components/JSONFiles/Affiliations.json`
- `pages/index.js` (SEO title, role line, hero intro)
- `public/profile-placeholder.svg` (replace with your profile image)
- `public/docs/sample-resume.pdf` and `public/docs/sample-cv.pdf`

## Notes

- Dependencies and scripts are preserved via `package.json` and `package-lock.json`.
- Contact links and downloadable documents are sample placeholders.
- Replace placeholder logos and sample URLs with your own data.
